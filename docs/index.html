hddmount-tui

1TB/2TB/4TB/8TB HDD를 안전하게 마운트하는 Go 기반 TUI + CLI 도구. SMART 체크, mdadm RAID1/RAID10, 비대화형 자동화까지 하나의 바이너리로. Ubuntu 22.04·24.04·26.04 이상을 지원하며, 26.10과 개발 버전도 CI에서 검사합니다. 향후 버전의 호환성은 개별 확인이 필요합니다. /var/www/html/uploads와 /var/www/html/public/uploads를 /data/uploads에 심볼릭 링크로 연결합니다.

설치하기 GitHub 릴리스 노트

주요 기능

안전한 마운트 마법사

루트 디스크 자동 제외, 파괴적 작업은 장치 경로 재입력으로 이중 확인. /data 같은 운영용 최상위 경로는 허용.

SMART 상태 체크

디스크 목록에서 SMART 헬스를 바로 확인하고, smartctl -a 상세 리포트를 그 자리에서 조회.

RAID1 / RAID10 구성

동일 용량 디스크를 골라 mdadm RAID 배열을 생성하고, mdadm.conf/initramfs까지 자동 갱신.

비대화형 CLI

프로비저닝 스크립트/cron용 list/mount/unmount/format-disk 지원. link-uploads로 재마운트 없이 업로드 링크만 구성합니다.

운영 로그 + 라벨

모든 마운트/언마운트/포맷 작업을 /var/log/hddmount.log에 기록, 마운트 포인트 기반 ext4 라벨 자동 설정.

busy 언마운트 복구

target is busy 상황에서는 fuser -ck로 점유 프로세스를 정리한 뒤 언마운트를 재시도.

CMS 폴더와 업로드 연결

uploads 아래에 contents, csv, log, monitor, photo, rrd, template 생성 후 권한/소유자를 설정합니다. 두 웹 업로드 경로는 /data/uploads에 연결하며, /data 미마운트 시 시스템 디스크로 대체하지 않습니다.

fstab 안전망

등록 전 자동 백업, findmnt --verify 검사, 실패 시 이전 fstab 복구로 재부팅 사고 방지.

자동화 CLI

sudo hddmount list --json
sudo hddmount smart --disk sdb --json
sudo hddmount mount --partition sdb1 --mountpoint /data --fstab
sudo hddmount link-uploads
findmnt /data
readlink -f /var/www/html/uploads
readlink -f /var/www/html/public/uploads
sudo hddmount unmount --mountpoint /data
sudo hddmount format-disk --disk sdb --confirm sdb --mountpoint /data/hdd1 --fstab

마운트 성공 시 마운트 경로의 uploads 하위에 표준 CMS 폴더를 생성하고, 마운트 경로 전체에 chmod -R 755, chown -R www-data:www-data를 실행합니다. /data 마운트를 확인한 뒤 두 웹 업로드 경로를 /data/uploads에 심볼릭 링크로 연결합니다. 링크 작업은 웹·Node 업로드 쓰기 중지 후 실행하며, 기존 데이터는 자동 복사·삭제·덮어쓰기하지 않습니다. 빈 폴더와 교체 가능한 잘못된 링크는 .uploads-before-data-*에 백업하며, 연결 실패 시 이전 변경을 복구합니다. link-uploads 연결 실패는 비영 종료 코드로 알리고, 일반 마운트 중 링크 연결 실패는 마운트를 유지한 채 오류로 알립니다. 언마운트 대상이 busy이면 fuser -ck 후 재시도합니다.
